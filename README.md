# UNO PARTY v1.2

スマホとPCで遊べる、UNO風のオンラインカードゲーム。
GitHubに入れてRailwayで動かせます。ゲーム画面と対戦サーバーは同じサービスです。

## 今回の更新

- 「あなたの番！」の大きな帯、開始表示、手札の明暗、画面の金色の枠で手番を表示。
- カードを出すまでの秒数と残り時間バー。残り5秒は赤色に変更。
- ワイルド／+4は選んだ色の英語ボイス（Red! / Yellow! / Green! / Blue!）。
- Reverse! / Skip! / Draw two! / Draw four! / UNO! と手番開始のボイス。
- 自分のターン残り10秒に警告音、5秒からカウント音。試合残り30秒・10秒にも案内、最後の5秒はカウント音。
- CPU（NPC）の強さを「かんたん／普通／強い」から選択。初期設定は「普通」で、以前より判断を緩めています。
- BGM・効果音・ボイスの個別音量と、時間警告のON/OFF。ボイスは同梱音源で、外部読み上げAPIは不要。

### v1.1から引き継いだ内容

- 送ってもらった画像・動画を参考に、青いロビーと木目のテーブルへ画面を作り直し。
- クラシックCPU対戦／友達との対戦／ルーム作成・参加の画面。
- 大きな手札・立体的なUNOボタン・配札カウントダウン・カード移動・色選択・結果画面。
- 個人戦2〜4人、2vs2、3分／5分／時間無制限。
- 7で手札交換、0–7ルール、スタッキング、強制プレイ。
- iPhone向けにBGMをMP3で再生。タップで音声を開始し、中断後の復帰処理も追加。
- 「音を開始」「音をテスト」で、スマホから再生状態を確認可能。

## すでに旧版を公開している場合

1. このZIPを解凍する。
2. 中身をGitHubの同じリポジトリに上書きしてCommitする。
3. Railwayの再デプロイ完了を待つ。自動デプロイOFFの場合はRedeployする。
4. スマホで公開URLを再読み込みして「音ありで遊ぶ」をタップ。

**public/assetsフォルダも必ずアップロードしてください。**
BGM・ボイスとテーブル背景が入っています。設定値は旧版と同じで使えます。

## 初めて公開する場合

1. GitHubに新しいリポジトリを作成し、ZIPの中身をアップロードしてCommitする。
2. `package.json`・`package-lock.json`・`Dockerfile`・`railway.json`が一番上にある状態にする。
3. Railwayの `New Project` → `Deploy from GitHub repo` → そのリポジトリを選ぶ。
4. デプロイ完了を待つ。Builder・起動コマンド・Healthcheckはファイルで設定済み。
5. サービスの `Settings` → `Networking` → `Public Networking` → `Generate Domain`。
6. 発行されたhttps://のURLを開く。友達にも同じURLを送れます。

| 項目 | 設定 |
|---|---|
| Builder | Dockerfile、自動判定 |
| Start Command | npm start |
| Healthcheck | /health |
| Replicas | 1 |
| PORT | Railwayの自動設定を使う |

BOT TOKEN・Discord・Supabase・外部APIキーは不要です。
Railwayの利用料は使用中のプランと使用量によります。

## 再起動後もルーム・手札を残す

1. このゲームのRailwayサービスにVolumeを接続する。
2. VolumeのMount Pathを `/data` に設定する。
3. サービスのVariablesに次の1つを追加する。

```text
DATA_DIR=/data
```

4. 再デプロイする。

Volumeがなければ、Railwayの再起動・再デプロイで保存が消える場合があります。
接続が切れても、同じ端末の同じブラウザで戻ると、自分の席と手札を復元します。
全員切断中は対戦を一時停止。最後の更新から24時間経ったルームは自動削除します。
端末の保存データを削除した場合は、元の席に戻れません。

## 遊び方

- 左上のアバターで名前とアバターを設定。
- **クラシック**：人数とルールを選び、CPU相手にすぐ対戦。
- **友達と遊ぶ**：「部屋を作成」でルームを作り、招待リンクか6文字のコードを共有。
- 空席にはCPUを追加可能。「CPUで空席を埋める」で一括追加。
- 同じ色・数字・記号のカードをタップ。出せなければ山札から1枚引く。
- ワイルドは色を選ぶ。7枚交換ONなら、7を出す時に相手を選ぶ。
- 自分の手札が2枚になったら、自分の番に **UNO!を押してから** 1枚出す。
- 手札が多い時は左右にスワイプ。スマホを横向きにすると広く使えます。
- 2vs2は向かいの席が味方。画面にTEAM 1／TEAM 2を表示します。


## CPUの強さ

クラシックの開始前、または待機ルームの「ルール設定」から選択します。対戦中は変更できません。

| 設定 | 動き |
|---|---|
| かんたん | ランダムなカードと色を中心に選択。時々1枚引き、UNOの指摘も控えめ |
| 普通（初期値） | 単純な色合わせを基本に、カードの選択を適度にランダム化 |
| 強い | 手札の色・記号と相手の公開されている枚数を見て判断。相手のUNOを止めやすい |

全レベルとも同じ配札とルールです。CPUは他プレイヤーのカード内容を見て選びません。

## スマホで音が聞こえない時

1. 公開URLをSafariなどのブラウザで開く。
2. 「音ありで遊ぶ」、またはスピーカーボタン →「音を開始」をタップ。
3. BGM・効果音・ボイスをONにし、各音量が0でないことを確認。
4. 「音をテスト」で3音、「ボイスをテスト」で英語の合成ボイスを鳴らす。端末の音量ボタンも上げる。
5. 別のアプリから戻って無音になったら、もう一度画面をタップする。

音楽・効果音はオリジナル、ボイスは英語の音声合成です。公式アプリの音源は使っていません。
音声の自動再生はブラウザによって制限されるため、最初のタップが必要です。
対応するiPhoneでは音声セッションをplaybackに設定し、Web Audioの中断からも復帰します。
非対応ブラウザ向けにも、BGMは通常のMP3再生を使います。
iPhoneのBGM音量は、端末の音量ボタンでも調節してください。
実機の音声出力は端末・ブラウザ・出力先の設定にも依存します。

## 採用ルール

- カード108枚。各ラウンドは数字カードから始まります。
- スキップは次の人を飛ばし、リバースは順番を逆にします。2人ならリバースもスキップ扱い。
- +2／+4は次の人が引いてお休み。スタッキングONでは、同じ+2同士・+4同士だけ重ねられます。
- +4は現在の色のカードを持っていない時だけ使えます。チャレンジはありません。
- 7枚交換：7を出す時に、相手を選んで手札を交換。
- 0–7：7で交換、0で手札を全員まとめて現在の進行方向の次の人へ渡します。
- 最後のカードが7・0なら、そのまま上がり。交換の後に手札1枚となった人は自動でUNO扱い。
- 強制プレイ：引いたカードが出せる時は、パスできません。時間切れ時は自動で出します。
- UNO忘れの指摘は、次の人が出すか引くまで。指摘されると2枚ドロー。
- ターン時間切れは1枚引いてパス。ドローが溜まっていればその枚数を引きます。
- 2vs2は座席1・3と座席2・4がチーム。どちらかが上がるとチームの勝ち。
- 制限時間で終わる時は、手札の合計点が少ない人が勝ち。同点なら手札の枚数、それも同じなら引き分け。
- チーム戦の時間切れは、2人の残りカード点数の合計で判定。同点は引き分け。
- 数字は数字の点数、記号は20点、ワイルドは50点。勝者に相手の残りカード点を加算。
- チーム戦では、相手チームの残り点数を味方2人それぞれに加算します。
- 最後のカードが+2／+4の場合も、相手が引いてから得点を集計します。
- 通信切断が30秒続くとCPUが代行。戻ると操作を引き継ぎます。

## ローカル起動・テスト

Node.js 22以上、推奨24。

```bash
npm ci
npm start
```

http://localhost:3000 を開きます。

```bash
npm run check
npm test
```

63項目のテストに、基本ルール・追加ルール・320試合のCPUシミュレーション、
通信・手札の非公開・再接続・再起動復元、音声の中断・復帰、ボイスの順序、警告の重複防止が含まれます。
iPhone実機のスピーカー出力を自動確認するテストではありません。
