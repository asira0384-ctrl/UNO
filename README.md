# UNO PARTY

スマホとPCのブラウザで遊べる、UNO風のオンラインカードゲームです。
GitHub → Railwayで、画面と対戦サーバーを1つのサービスとして動かせます。

## 入っている機能

- 2〜4人のオンライン対戦。6文字のルームコード・招待リンクで参加。
- CPUを最大3人追加。1人ですぐに遊べる練習モード。
- スマホの縦画面・横画面、PCに対応。手札が多い時は横にスワイプ。
- 108枚のカード、スキップ、リバース、+2、ワイルド、+4。
- UNO宣言・UNO忘れの指摘、勝敗表示、累計スコア、再戦。
- 重ねがけのON/OFF、15・30・60秒のターン時間設定。
- オリジナルBGM、カード・ドロー・UNO・勝利の効果音。個別の音量調節。
- アバター、リアクション、対戦履歴、カードの移動演出。
- 再接続、30秒切断時のCPU代行、ホストの引き継ぎ。
- Volumeを設定すれば、ルーム・手札・得点を再起動後も復元。
- サーバー側でルールを判定。他人の手札や再接続トークンはクライアントに配信しません。

## GitHubとRailwayの設定

### 1. GitHubへアップロード

1. このZIPを解凍する。
2. GitHubで新しいリポジトリを作成する。Privateでも大丈夫。
3. `Add file` → `Upload files` で、解凍したフォルダの**中身**をアップロードしてCommitする。
4. リポジトリを開いて、`package.json`、`package-lock.json`、`Dockerfile`、`railway.json` が一番上にあることを確認。

`public`・`src`・`test` はフォルダごとアップロードしてください。
`node_modules` や `.env` のアップロードは不要です。

### 2. Railwayで動かす

1. Railwayで `New Project` → `Deploy from GitHub repo`。
2. 今作ったリポジトリを選ぶ。
3. 自動ビルドとデプロイを待つ。`Dockerfile` と `railway.json` で起動設定済み。
4. サービスの `Settings` → `Networking` → `Public Networking` → `Generate Domain`。
5. 発行された **https:// のURL** を開く。スマホでも同じURLで遊べます。

Start Commandは `npm start`。Healthcheckは `/health`。
`PORT` はRailwayが設定する値を自動で使います。自分で変える必要はありません。
BOT TOKEN、Discord、Supabase、外部APIキーは不要です。

ゲームの状態を1つのサーバーが管理するため、**Replicasは1**にしてください。
GitHubへの更新は、Railwayの自動デプロイで反映できます。
Railwayのホスティング利用料は、利用中のプラン・使用量に応じて発生します。

### 3. 再起動してもデータを残す設定

この設定をすると、アプリを更新しても24時間以内のルームと手札を復元できます。

1. RailwayのこのサービスにVolumeを追加する。
2. Mount Pathを **`/data`** にする。
3. サービスの `Variables` に次を追加する。

```text
DATA_DIR=/data
```

4. 再デプロイする。

Volumeなしの場合は、Railwayの再起動・再デプロイで保存データが消える場合があります。
再起動では通信が一度切れますが、同じ端末の同じブラウザで開くと自動でルームに戻ります。
再接続に使う端末データを消した場合、元の席には戻れません。
全員が切断したゲームは一時停止し、誰かが戻ると再開します。
最後の操作・更新から24時間経ったルームは自動で削除されます。

## 遊び方

1. 名前とアバターを決めて「ルームをつくる」。
2. 「友達を招待する」でリンクを送るか、6文字のコードを伝える。
3. 友達が入ったら、ホストが「ゲームスタート」。2人以上で始められます。
4. 光っているカードをタップして出す。出せない時は山札から1枚引く。
5. 引いたカードが出せる場合は、出すか「パスする」を選べます。
6. 手札が2枚になったら、自分の番に **UNO! を押してから** 1枚出す。
7. 手札をすべて出すと勝利！

1人の時は「CPUと練習する」で、CPU3人との対戦がすぐ始まります。

### 音について

ブラウザの仕様で、**最初に画面をタップしてから** 音が始まります。
右上のスピーカーボタンで、BGMと効果音を別々にON/OFF・音量調節できます。
画面を閉じたり別のアプリに移動したりすると、音は一時停止します。
音が聞こえない場合は、端末の音量・消音設定も確認してください。
外部の音楽ファイルや公式アプリの音源は使っていません。

### iPhoneでアプリのように開く

Safariで公開URLを開いて、共有ボタン →「ホーム画面に追加」。
ホーム画面のアイコンから起動できます。インターネット接続は必要です。

## 採用しているルール

- 同じ色・数字・記号、またはワイルドを出せます。
- ワイルド+4は、現在の色のカードを持っていない時だけ出せます。チャレンジはありません。
- +2・+4は次の人がその枚数を引き、その人の番を飛ばします。
- 2人対戦ではリバースもスキップとして動作します。
- 重ねがけONでは、同じ+2同士・+4同士だけ重ねられます。違う種類は重ねられません。
- UNOを忘れた場合、次の人がカードを出す・引くまでに指摘されると2枚引きます。
- 時間切れは1枚引いてパス。ドローが溜まっていればその枚数を引きます。
- 最後に+2や+4で上がった場合も、相手はカードを引いてから集計します。
- 相手の残りカードの点数を勝者に加算。数字は数字の点数、記号は20点、ワイルドは50点です。
- 各ラウンドは数字カードから始まります。

## PCでローカル起動する場合

Node.js 22以上（推奨24）が必要です。

```bash
npm ci
npm start
```

http://localhost:3000 を開きます。
同じWi-Fiのスマホでは、PCのローカルIPアドレスとポート3000を指定して開けます。
WindowsのファイアウォールでNode.jsのプライベートネットワーク通信を許可してください。
友達と離れた場所から遊ぶ場合は、Railwayで公開したURLを使ってください。

## 検証と構成

```bash
npm run check
npm test
```

ゲームルール、100試合のCPUシミュレーション、別クライアント同士の通信、手札の非公開、
再接続、サーバー再起動後の復元を検証するテストが入っています。

```text
server.js             HTTP・リアルタイム通信・保存・CPU・再接続
src/game.js           ゲームルールと配札
public/index.html     ページ本体
public/app.js         画面・ルーム操作・カード演出
public/styles.css     スマホ・PCのレイアウト
public/audio.js       オリジナルBGM・効果音
railway.json          Railwayのデプロイ設定
Dockerfile            Node.js 24の実行環境
test/                 ルール・通信・復元テスト
```

このプロジェクトは非公式のUNO風カードゲームです。公式アプリ・公式音源の配布物ではありません。
