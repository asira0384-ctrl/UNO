# Original project assets

- `public/assets/table-room.webp`: Original game background created with the built-in imagegen tool, then encoded as WebP for this project. The uploaded screenshots and recording were used to understand the desired layout and mood; the generated background contains no copied UI or player information.
- `public/assets/audio/scene-1.mp3` through `scene-5.mp3`: Five original 60-second instrumental pieces composed and synthesized by `scripts/make-playlist.py`: marimba (112 BPM), lounge keys (94), synth (126), mellow keys (82), steelpan (104).
- `public/assets/audio/party-loop.mp3`: Earlier original instrumental loop, retained for compatibility.
- `public/assets/backgrounds/*.svg`: Four original vector table environments, drawn for this project.
- `public/assets/audio/sound-test.mp3`: Original three-note test tone generated by the same script.
- `public/assets/avatars/robot-*.svg`: Eight original vector image portraits. Player-selected pictures are resized on the client and stored only as bounded raster data.
- `public/assets/audio/voice/*.mp3` and `voice-calls.mp3`: 35 newly synthesized Japanese deliveries (7 calls × 5), generated with Kokoro-82M via kokoro-onnx. The project defines a mixed style embedding using jf_alpha, jf_tebukuro and jm_kumo, different pace/punctuation per delivery, EQ, consistent loudness and short stereo room response. These are new synthesized game calls, not human actor recordings and not a voice model trained from scratch. Model: https://huggingface.co/hexgrad/Kokoro-82M (Apache 2.0); renderer: https://github.com/thewh1teagle/kokoro-onnx (MIT). Upstream voice/data credits are preserved in `public/licenses/kokoro-voices.md`; the model/code license is in `public/licenses/kokoro-apache-2.0.txt`. Previous Mei/HTS calls are no longer referenced by this version. Model weights and synthesis runtimes are not shipped. The development script disables runtime telemetry before importing the engine. Rebuild using `scripts/make-voice-calls.py`.
- `public/assets/uno-call.svg` and `public/assets/app/*`: Original vector button, icon composition and PNG exports built with `scripts/make-app-icons.py`. The Latin logo lettering uses DejaVu Sans Bold outlines, with the same Bitstream/DejaVu permission notice; the katakana caption is drawn as vector strokes.
- `public/numerals.js`: Vector outlines derived from DejaVu Sans Condensed Bold digits, with 6/9 underlines added. DejaVu changes are public domain; underlying Bitstream notice and permission are included in `public/licenses/dejavu.txt`.
- Runtime attribution is available at `public/credits.html`, linked from sound settings.
- Paper/dealing sounds are synthesized in Web Audio, with timing informed by the supplied recording, not extracted from the reference soundtrack.
- Playing cards, house illustrations, icons, buttons, and effects are rendered in SVG, CSS, and JavaScript.

## Background prompt

Use case: stylized-concept. Asset type: background art for a mobile online card game, landscape 2.16:1 composition, high-quality original 3D casual game environment. A large EMPTY oval honey maple wooden card table, seen from a high three-quarter top-down angle, almost filling the frame, with an elegant thick rounded beveled wooden rim. The light warm tabletop is clean, smooth, with fine subtle woodgrain and ample empty playing space in the whole center and bottom half. Four cozy terracotta upholstered chairs sit around the OUTSIDE edges; a friendly cozy game room with small books, a muted red carpet and wooden floor is only visible around the far periphery. Warm inviting soft studio-like lighting, polished rounded 3D mobile game rendering, detailed but visually calm. The empty tabletop is the hero and occupies about 85 percent of the image width and 88 percent of the height, centered, extending near the bottom so UI cards can overlay. No writing, no logos, NO playing cards, NO UI, NO buttons, NO game pieces, NO people, NO avatars, NO currency, NO numbers, NO watermarks. Original environment art, not a screenshot.
